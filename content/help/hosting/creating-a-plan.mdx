---
title: Creating a Plan
description: How to create and set up a new event or gathering in Leaf.
---

A plan in Leaf is an event or gathering where people can RSVP and collaborate. Here's how to create one.

## Start a New Plan

1. Go to your calendar
2. Click **Create Plan** or click a date to start planning
3. Enter a plan name (e.g., "Pizza night", "Hiking trip")
4. Add a description (optional but helpful)
5. Set the date and time

## Add Details

- **Location**: Enter an address or location name
- **Duration**: Set how long the plan will run
- **Max attendees**: Cap the number of people (optional)
- **Photo**: Add a cover image to make it stand out

## Sharing Options

- **Public**: Anyone with the calendar link can see and RSVP
- **Invite only**: Send specific invites to people you choose
- **Allow chat**: Enable a discussion thread for attendees to chat

## Publish

Click **Create** to publish your plan. Everyone in your calendar will see it and can start RSVPing immediately.

## What Happens Next

Once created, people can:
- RSVP yes, no, or maybe
- See who else is attending
- Chat about the plan
- Get reminders as the date approaches
